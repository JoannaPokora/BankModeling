# Applications of mathematical modeling in banking

Projects focused on mathematical modeling in the banking sector. Each folder contains an HTML report and Jupyter Notebook script. The repository includes:

* **bank_portfolio_analysis** - identification of non-performing porfolios and estimation of their occurrence probability using a decision tree;
* **banking_sector_analysis** - analysis of changes in the banking sector between 2010 and 2024, including changes in the number of selected types of banking facilities and employees;
* **scoring_model** - estimation of the probability of credit problems within two years using logistic regression and assessment of credit risk;
* **xgboost_classification** - prediction of whether a client will open a bank deposit using an XGBoost model with selected predictors.
